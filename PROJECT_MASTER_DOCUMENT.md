## 22. DATABASE

**Provider:** Convex (serverless document DB) — **NOT Prisma.** Schema: `src/convex/schema.ts`.

```
users (from authTables template)         — email index
  ├─ managed by Convex Auth; only touched by users.currentUser query

conversations                            — index by_createdAt(createdAt)
  fields: name, email, phone?, pathway(general|volunteer|partnership|prayer|media),
          message, status?("new"), createdAt
  written by: conversations.submitConversation
  read by:  NOTHING yet (no admin view)

donationIntents                          — index by_createdAt(createdAt)
  fields: name, email, phone?, frequency(one-time|monthly), amountInr,
          message?, status("submitted"), createdAt
  written by: donations.submitDonationIntent (fallback path)
  read by:  NOTHING yet

donations                                — indexes by_status(status), by_createdAt(createdAt)
  fields: conversationReference?, donorName, donorEmail, frequency, amountInr,
          currency, provider, providerPaymentId?, status(created|paid|failed|refunded), createdAt
  written by: donations.recordDonation (internal), donations.markPaid (internal)
  read by:  markPaid (by_status scan to find matching session id)

authTables (Convex Auth)                 — sessions, accounts, authUsers, verificationCodes…
```

**Relationships:** none enforced. `donations.providerPaymentId` ↔ Stripe Session id is the only cross-reference; `conversationReference` field exists but is never populated.
**Migrations:** none — schema push is automatic (`convex dev --once`). **Seed data:** none.
